---
title: Repair links to Scratch cells and ranges
description: Keep live note references stable and point an existing link to a new source.
---

**Choose Relink Note Source to update an existing live link.** Select the new range on the sheet that contains the note, then choose the link to update. Restoring a deleted sheet reconnects its existing links. [Repair a note link](/docs/notes-and-obsidian#repair-a-note-link).
