# A/B scenarios removed (2026-11-12)

**A/B scenarios have been removed from Scratch.** The comparison window and Compare A/B Scenario command are gone.

Use ordinary cell editing and Undo to change an input and restore it. [Read the grid guide](https://scratch.itsryan.me/docs/grid.md).
