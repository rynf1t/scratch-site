# Named ranges, sheet copies and file import (2026-11-12)

**Jump back to a named range.** Name a selection from the sheet menu or command palette. Use **Go to Named Range** to find it again, even after rows or columns move. [Named ranges guide](https://scratch.itsryan.me/docs/grid.md#save-a-named-range).

**Duplicate a sheet or import a file.** Make a copy with its formulas, formatting and notes. Use **Import CSV or TSV** to open a file in its own sheet. [Sheet guide](https://scratch.itsryan.me/docs/grid.md#duplicate-a-sheet-or-import-a-file).
