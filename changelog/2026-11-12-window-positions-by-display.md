# Remember a window layout per display (2026-11-12)

**Scratch remembers a separate window position and size for each display.** Move your pointer to the display you want, then open Scratch. Move or resize the compact window to set that display’s layout.

**Expand** fills the usable space on the current display. **Compact** brings back the layout for that display. [Resize the window](https://scratch.itsryan.me/docs/grid.md#resize-the-window).
