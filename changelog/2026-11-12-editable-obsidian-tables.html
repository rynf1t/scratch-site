Editable Obsidian tables

Run Sync Editable Table with Obsidian to make an editable copy of a Scratch sheet in your vault.

Open the copy from Scratch, edit in either app, and sync again. Edits to different cells merge. If the same cell changes to different values in both apps, Scratch shows the address so you can resolve it. Changes pulled into Scratch can be undone in one step.

The Power Tables community plugin can edit and recalculate compatible formulas. Read the editable table guide.
