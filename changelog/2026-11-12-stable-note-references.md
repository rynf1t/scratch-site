# Repair links to Scratch cells and ranges (2026-11-12)

**Choose Relink Note Source to update an existing live link.** Select the new range on the sheet that contains the note, then choose the link to update. Restoring a deleted sheet reconnects its existing links. [Repair a note link](https://scratch.itsryan.me/docs/notes-and-obsidian.md#repair-a-note-link).
